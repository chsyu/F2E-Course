Kb_SVGAnimations

GSAP × SVG 動畫

接續 Ka 的互動 SVG：這裡用 GSAP 示範兩種常見手法—— stroke 寫字／畫線，以及 ScrollTrigger 捲動連動。

1. 寫字（畫線）動畫

原理：量出 path 長度，設 stroke-dasharray / stroke-dashoffset，再用 gsap.to 把 offset 推到 0， 看起來就像筆尖在畫線。不需付費的 DrawSVGPlugin。

2. 搭配 Scroll 的 SVG 動畫

用 ScrollTrigger 把時間軸綁在捲動進度上（scrub）， 並以 pin 固定畫面，讓路徑、地標與移動物件跟著滾輪進度前進。 往下捲即可預覽。

捲動進度 0%

繼續往下捲，路線會跟著進度畫完

捲動段落結束

pin 解除後回到一般文件流。可再往上捲，動畫會依 scrub 倒播。
